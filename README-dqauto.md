# DQ自動周回(ブラウザゲーム自動操作アプリ)

指定されたブラウザゲーム(`app.h3z.jp` の「ドラゴンクエストアドベンチャー」)に自動ログインし、
「シングルバトル → アレフガルド選択 → ステータス」の周回操作を、一定時間おきに自動で
繰り返すAndroidアプリです。マンガ翻訳アプリ・BabyCallとは独立した Gradle モジュール
(`dqauto`)として同じリポジトリに同居しています。

## 重要な注意事項

- **利用規約について**: 多くのオンラインゲームは自動操作(BOT)を利用規約で禁止しています。
  このツールの利用によってアカウントが凍結・削除されるなどのリスクは、利用者ご自身の
  判断・責任でご検討ください。
- **ログイン情報について**: IDとパスワードは、アプリ内のログイン設定画面から入力し、
  **この端末のアプリ内データ(SharedPreferences)にのみ保存されます**。ソースコードや
  Gitの履歴には一切含まれません(コミットされることはありません)。
- **サイトの実際の構造は未確認です**: 開発環境のネットワークポリシーにより、
  `app.h3z.jp` に開発中は直接アクセスできませんでした。そのため、クリック対象の
  リンク文言(「シングルバトル」「アレフガルド」「ステータス」)は、伝えていただいた
  内容をもとにコードに直接埋め込んでいます。実際のページの文言と異なる場合はリンクが
  見つからず、画面下部に「〇〇が見つかりません。再試行します…」と表示され続けます。
  その場合は `dqauto/src/main/java/com/dqauto/MainActivity.kt` の `STEPS` の文字列を
  実際の表示文言に合わせて修正し、再ビルドしてください。

## 仕組み

1. アプリを開くとログイン設定ダイアログが表示されます(初回のみ)。IDとパスワードを
   入力すると、`mode=log_in` のURLにその場でログインし、WebView上にゲーム画面が
   表示されます。
2. 「自動化を開始」を押すと、以下を繰り返します。
   1. ページ内から文字列「シングルバトル」を含むリンク/ボタンを探してクリック
   2. ページの読み込み完了を待つ
   3. 文字列「アレフガルド」を含むリンクをクリック
   4. ページの読み込み完了を待つ
   5. 文字列「ステータス」を含むリンクをクリック
   6. ページの読み込み完了を待つ → 1周完了
   7. 30秒待機してから、また1に戻る
3. 各手順でリンクが見つからない場合は2秒後に自動で再試行します(ページの読み込みが
   まだ終わっていない、想定外の画面が出ている、などの場合に備えたリトライです)。

## 動作範囲

自動化は**このアプリの画面を表示している間だけ**動作します。ホーム画面に戻ったり
他のアプリに切り替えたりすると自動的に一時停止し、この画面に戻ると再開します
(バックグラウンドで動き続ける常駐サービスにはしていません。画面をつけっぱなしに
しておく必要があります)。

## ビルドする

```bash
./gradlew :dqauto:assembleDebug
```

`dqauto/build/outputs/apk/debug/dqauto-debug.apk` が生成されます。

## 既知の制限

- 待機時間(現在30秒固定)は `Prefs.kt` の `DEFAULT_CYCLE_INTERVAL_SECONDS` で変更できます。
- ネットワークエラーや、ログイン失敗・セッション切れなどの異常系は特別なハンドリングを
  しておらず、単にリンクが見つからないものとして再試行し続けます。
- 「アレフガルド」以外の選択肢を選びたい場合や、周回の手順自体を変えたい場合は、
  `MainActivity.kt` の `STEPS` リストを編集してください。
