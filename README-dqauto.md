# DQ自動周回(ブラウザゲーム自動操作アプリ)

指定されたブラウザゲーム(`app.h3z.jp` の「ドラゴンクエストアドベンチャー」)に自動ログインし、
ステータス画面の「シングルバトル」欄で対戦相手を「アレフガルド」に選んで「モンスターを
しばく」→「ステータス」に戻る、という周回操作を一定時間おきに自動で繰り返すAndroidアプリ
です。ステータス画面に戻るたびに、キャラクターデータの「作戦」が「どとうのひつじ」に
なっているかも確認し、なっていなければ自動で直します。マンガ翻訳アプリ・BabyCallとは
独立した Gradle モジュール(`dqauto`)として同じリポジトリに同居しています。

## 重要な注意事項

- **利用規約について**: 多くのオンラインゲームは自動操作(BOT)を利用規約で禁止しています。
  このツールの利用によってアカウントが凍結・削除されるなどのリスクは、利用者ご自身の
  判断・責任でご検討ください。
- **ログイン情報について**: IDとパスワードは、アプリ内のログイン設定画面から入力し、
  **この端末のアプリ内データ(SharedPreferences)にのみ保存されます**。ソースコードや
  Gitの履歴には一切含まれません(コミットされることはありません)。
- **サイトの実際の構造は未確認です**: 開発環境のネットワークポリシーにより、
  `app.h3z.jp` に開発中は直接アクセスできませんでした。そのため、以下の手順・文言は
  スクリーンショットと説明をもとにコードに直接埋め込んでいます。実際のページと異なる
  場合は対象が見つからず、画面下部に「〇〇が見つかりません。再試行します…」と表示され
  続けます。その場合は `dqauto/src/main/java/com/dqauto/AutomationService.kt` の
  `STEPS` を実際の表示に合わせて修正し、再ビルドしてください。

## 仕組み

WebView(ログインセッション)は**アプリ全体で1つだけ**です。`AutomationService`
(バックグラウンドサービス)がこのWebViewを生き続ける間ずっと所有し、周回操作は常に
この1つのセッションに対して行われます。アプリ画面(`MainActivity`)は自分専用の
WebViewを持たず、画面が表示されている間だけこのWebViewを画面内に借りて表示します。
そのため、アプリ画面に映っている内容は常に自動化が実際に操作しているのと**同じ画面**
であり、ボタンやリンクをタップして手動操作することもできます(自動周回中でも、次の
自動操作までの間であれば手動操作が割り込む形になります。手動操作にじっくり時間を
使いたい場合は、先に「自動化を停止」を押してください)。アプリ画面を閉じる・裏に
回すと、WebViewはアプリ画面から外れてバックグラウンドサービス側に戻り、非表示のまま
周回を継続します。

1. アプリを開くとログイン設定ダイアログが表示されます(初回のみ)。IDとパスワードを
   入力すると、その場で `mode=log_in` のURLにログインし、アプリ画面にゲーム画面が
   表示されます。
2. 「自動化を開始」を押すと、まだログインしていなければ自分でログインした上で
   以下を繰り返します。
   1. ステータス画面の「シングルバトル」欄にあるプルダウン(対戦相手選択)から
      「アレフガルド」を選び、その隣の「モンスターをしばく」ボタンをクリック
   2. ページの読み込み完了を待つ(バトル結果画面)
   3. 文字列「ステータス」を含むリンクをクリック
   4. ページの読み込み完了を待つ(ステータス画面に復帰)
   5. キャラクターデータの「作戦」が「どとうのひつじ」になっているか確認する。
      なっていれば何もせず7へ。なっていなければ:
      1. 「作戦」の横の「作戦変更」ボタンをクリック
      2. 「どとうのひつじ」の横のチェックボックスにチェックを入れ、
         「変更するぞ!」ボタンをクリック
      3. 「ええがな!」ボタンをクリック
   6. → 1周完了
   7. 30秒待機してから、また1に戻る
3. 各手順で対象(プルダウン/ボタン/リンク/チェックボックス)が見つからない場合は2秒後に
   自動で再試行します。8回連続で見つからない場合は、想定外の画面(お知らせ・広告など)
   に迷い込んでいる可能性が高いとみなし、自動で再ログインしてから同じ手順をやり直します。
   プルダウンの選択は、「モンスターをしばく」を含むボタンを探し、その祖先要素の中から
   最初に見つかった`<select>`を対象にしています(同じ行にある想定)。「作戦」がすでに
   「どとうのひつじ」になっているかどうかは、「作戦変更」ボタンの祖先要素をさかのぼり、
   「作戦」という文字を含む要素の中に「どとうのひつじ」という文字があるかで判定して
   います。
4. クリックが成功したと判定してもページの読み込みが実際には起きない場合(サイトの
   確認ダイアログや、AJAXでの部分更新など)に備え、8秒たっても読み込み完了が来なければ
   強制的に次の手順に進みます。また、ページ側が確認ダイアログ(JavaScriptの
   confirm/alert)を出す場合は自動的に「OK」を選んで進めます。

## 動作範囲(バックグラウンドで動作します)

自動化は**フォアグラウンドサービス**として動作するため、アプリ画面を閉じたり
他のアプリに切り替えたりしても止まりません。「自動化を開始」を押すと通知が表示され、
その通知が出ている間は裏で周回を続けています(この通知は動作中である印なので、
スワイプでは消せません)。止めるにはアプリを開いて「自動化を停止」を押してください。
アプリを再度開くと、動作中かどうか・直近の状態が画面に反映されます。

## ビルドする

```bash
./gradlew :dqauto:assembleDebug
```

`dqauto/build/outputs/apk/debug/dqauto-debug.apk` が生成されます。

## 既知の制限

- 待機時間(現在30秒固定)は `Prefs.kt` の `DEFAULT_CYCLE_INTERVAL_SECONDS` で変更できます。
- ネットワークエラーや、ログイン失敗・セッション切れなどの異常系そのものへの個別対応は
  なく、単に対象が見つからないものとして再試行・再ログインを繰り返します。
- 「アレフガルド」以外の選択肢を選びたい場合や、周回の手順自体を変えたい場合は、
  `AutomationService.kt` の `STEPS` リストを編集してください。
- 自動周回中にアプリ画面から手動操作すると、次の自動操作(プルダウン選択やクリック)
  とタイミングが重なる可能性があります。手動操作をしっかり行いたいときは、先に
  「自動化を停止」を押してから操作してください。
